# Titan Admin · 本期后台需求说明

> 本文记录本期新增后台管理端的产品方向、目录规划与记账模块原型范围。

## 1. 背景

现有 VibCheck 项目已包含个人端 PWA，覆盖日程、统计、记账、工程管理等移动端能力。

本期开始新增两个独立模块：

| 模块 | 使用场景 | 终端 |
|------|----------|------|
| Titan Admin | 后台管理、项目经营、费用管理、人员管理 | PC 浏览器 |
| worker-web | 工人端查看与填报 | 手机 Web |

后台产品名称统一为：**Titan Admin**。

## 4. 本期后台记账模块范围

后台记账管理面向 PC 浏览器，目标是提供比手机端更高效的数据浏览、筛选、编辑与管理能力。

### 4.1 页面结构

后台记账模块原型包含：

| 区域 | 内容 |
|------|------|
| 左侧导航 | 总览、记账管理、账单分类、工程管理、工人账号、基础配置 |
| 顶部操作区 | 导出、新增分类、新增账单 |
| KPI 区 | 本月支出、账单笔数、工程支出、未关联账单 |
| 筛选区 | 开始日期、结束日期、分类、工程、关键词 |
| 账单明细 | 账单列表、编辑、删除 |
| 账单分类列表 | 分类维护、启用/停用、恢复 |
| 右侧信息区 | 分类支出占比、高支出工程 |
| 右侧抽屉 | 新增账单、编辑账单分类 |

### 4.2 账单明细字段

账单明细列表展示以下字段：

| 字段 | 说明 |
|------|------|
| 日期 | 账单发生日期 |
| 金额 | 支出金额 |
| 分类 | 账单分类 |
| 关联工程 | 可为空，未关联时显示“未关联” |
| 负责人 | 账单负责人或经办人 |
| 描述 | 款项说明 |
| 操作 | 编辑、删除 |

### 4.3 筛选能力

后台记账列表需要支持：

| 筛选项 | 说明 |
|--------|------|
| 开始日期 / 结束日期 | 按账单日期范围筛选 |
| 分类 | 按账单分类筛选 |
| 工程 | 按关联工程筛选 |
| 关键词 | 搜索负责人、描述、工程名 |

### 4.4 新增 / 编辑账单

账单通过右侧抽屉完成新增或编辑。

表单字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 日期 | 是 | 账单日期 |
| 金额 | 是 | 支出金额 |
| 分类 | 是 | 账单分类 |
| 负责人 | 否 | 经办人或负责人 |
| 关联工程 | 否 | 可选择“不关联工程” |
| 描述 | 否 | 款项说明 |

## 5. 账单分类管理

原记账模块缺少后台视角下的账单分类编辑与列表页，本期已在原型中补齐。

### 5.1 分类列表字段

账单分类列表展示：

| 字段 | 说明 |
|------|------|
| 分类名称 | 分类展示名 |
| 父级 | 一级分类显示“一级分类”，子分类显示对应父级名称 |
| 状态 | 启用 / 停用 |
| 本月金额 | 当前月份该分类下账单金额合计 |
| 账单数 | 当前月份该分类下账单数量 |
| 最近使用 | 最近一条使用该分类的账单信息 |
| 操作 | 编辑、停用、恢复 |

### 5.2 分类编辑字段

分类通过右侧抽屉编辑。

表单字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 分类名称 | 是 | 分类名称 |
| 父级分类 | 否 | 为空表示一级分类；选择一级分类后，该分类成为其子分类 |
| 显示颜色 | 是 | 用于列表、图表、标签展示 |
| 状态 | 是 | 启用 / 停用 |
| 说明 | 否 | 分类用途说明 |

### 5.3 分类状态规则

| 场景 | 规则 |
|------|------|
| 启用分类 | 可在新增 / 编辑账单时选择 |
| 一级分类 | `parent_id = null`，可作为其他分类的父级 |
| 子分类 | `parent_id` 指向一个一级分类；账单仍直接关联具体分类 ID |
| 调整父级 | 编辑分类时可把子分类改为一级分类，或挂到其他一级分类下 |
| 停用分类 | 不再用于新账单选择，但历史账单保留原分类 |
| 停用分类恢复 | 恢复后重新出现在账单分类选择中 |
| 删除分类 | 原型中保留“删除”入口，实际实现前需确认是否采用逻辑删除 |

## 6. 后续待确认

以下内容尚未进入实现阶段，需要后续确认：

| 问题 | 说明 |
|------|------|
| 后台登录权限 | Titan Admin 是否需要独立登录与角色权限 |
| 工人端权限 | 工人端可查看哪些项目、费用、任务 |
| 分类删除策略 | 账单分类是否允许物理删除，还是统一逻辑删除 |
| 导出范围 | 导出 Excel / CSV / PDF，按筛选条件还是全量 |
| API 分组 | 后台接口是否统一使用 `/api/v1/admin/...` |
| 多用户模型 | 是否继续沿用默认 `user_id=1000`，还是进入真实用户体系 |
