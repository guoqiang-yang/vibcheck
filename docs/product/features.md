# VibCheck · Features (MVP)

## MVP 边界说明
- 默认用户 user_id=1000, name=Oscar，不做登录/注册页面
- 分类固定为 4 个默认值：工作 / 学习 / 运动 / 会议（硬编码）
- 分类自定义管理留到 Post-MVP

---

## Feature 1：日历时间轴页（Calendar View）

### 布局规范（手机端）
- 页面占满整个视口高度（100dvh），**不留底部空白**
- 顶部：月份导航栏（固定，不随内容滚动）
- 主体：时间轴列表区域，**内部纵向滚动**（overflow-y: auto）
- 时间轴头部（时间刻度行）固定在列表顶部，随主体横向滚动

### 必须有（MVP）
- 以月为单位，每天一行，横向时间轴（04:00 – 24:00）
- 每天两行：
  - 上层「实际行」：已发生事项（实色块）+ 灵感标记
  - 下层「计划行」：计划事项（虚线框），过期后淡化保留
- 色块颜色 = 分类颜色
- 色块透明度 = 投入度（高→实色 / 中→半透明 / 低→淡色）
- 灵感在实际行以 ⚡ 图标标记，仅占一个时间点，无时长
- 支持前后月切换，快速跳回"今天"
- 点击某天跳转到「日期详情页」

### 暂不做（Post-MVP）
- 搜索 / 筛选
- 农历 / 节假日显示

---

## Feature 2：日期详情页（Daily Detail View）

### 必须有（MVP）
- 展示当天全部事项（实际 + 计划 + 灵感）列表
- 支持新增事项（底部弹出表单）
- 支持编辑 / 删除事项

### 事项字段
| 字段 | actual | planned | inspiration |
|------|--------|---------|-------------|
| 标题 title | 必填 | 必填 | 必填 |
| 分类 category | 必填 | 必填 | — |
| 开始时间 start_time | 必填 | 必填 | 必填（时间点）|
| 结束时间 end_time | 必填 | 必填 | — |
| 投入度 engagement（高/中/低）| 必填 | — | — |
| 备注 note | — | — | — |（MVP 不对用户开放）|
| 过程详情 content | 选填 | 选填 | 选填 |（有内容才显示）|

### 暂不做（Post-MVP）
- 复盘统计
- 里程碑节点

---

## Feature 3：数据层

### 表结构（详见 database/db.sql）

**t_users**：用户表，MVP 预置 id=1000 / name=Oscar

**t_categories**：分类表，绑定 user_id，MVP 预置 4 条默认分类
- 工作 `#4F86E8` / 学习 `#F0883A` / 运动 `#2DBD8A` / 会议 `#9B72E8`

**t_time_events**：时间事件表，统一存储实际事项、计划事项、灵感
- `type` 枚举：actual / planned / inspiration
- `engagement` 枚举：high / mid / low（仅 actual 有值）
- `category_id`：灵感时为 null
- `end_time`：灵感时为 null
- `note`：简短备注
- `content`：过程详情（长文）

---

## Post-MVP 功能池
- 分类自定义管理（名称 + 颜色，绑定 user_id）
- 复盘统计（按分类 / 按周月汇总）
- 长期任务 + 里程碑
- 用户登录 / 注册
- 数据导出
- 通知提醒
