# VibCheck · Product Vision

## 一句话定义
VibCheck 是一款以"天"为单位的个人生活记录与规划工具，帮助用户记录每天做了什么、感受如何，并通过可视化颜色体系反映事项状态与精力投入。

## 目标用户
- **当前阶段**：创作者/开发者本人，深度个人使用，打磨产品体验
- **未来阶段**：有自我管理需求、不满足于传统日历工具的个人用户

## 核心使用场景

### 场景 1：未来规划（Planning）
- 提前安排日程事项（会议、约定、截止日期等）
- 为长期任务设置里程碑节点，在时间轴上可见
- 目的：减少遗漏，对未来有掌控感

### 场景 2：当日记录（Logging）
- 随时记录今天做了什么、花了多少时间
- 捕捉临时想法、灵感、思考片段
- 目的：留下真实的生活轨迹，供日后复盘

### 场景 3：定期复盘（Review）
- 按天/周/月聚合已记录的事项
- 看到自己的时间都去了哪里，哪类事情做得多/少
- 目的：优化时间分配，持续改进

## 与传统日历 App 的差异

| 维度 | Apple Calendar / Google Calendar | VibCheck |
|------|-----------------------------------|----------|
| 设计取向 | 通用、功能导向 | 个人化、情绪友好 |
| 记录粒度 | 事件时间段 | 事件 + 状态 + 想法 + 灵感 |
| 状态表达 | 无 | 颜色 + 透明度（反映完成度/精力状态） |
| 信息密度 | 低（只有标题+时间） | 高（支持备注、分类、标签） |
| 复盘支持 | 弱 | 按类别汇总、时间分布统计 |

## 产品原则
1. **按天为核心单位**：每一天是一个独立的"日记页"
2. **记录优先于管理**：降低记录门槛，不应该因为麻烦而不记
3. **视觉传达状态**：颜色/透明度是信息的一部分，不只是装饰
4. **数据属于用户**：设计上为未来多用户/数据导出预留空间
