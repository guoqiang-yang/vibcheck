## 2026-06-03 · 需求细化与文档建立

### 背景
MVP（v1.0）完结后，用户提出 v2.0 三个方向的原始需求（见 `raw_require.md`）。

### 需求细化过程

**原始需求 → 细化确认的关键决策：**

| 问题 | 用户决策 |
|------|---------|
| ⚡ 图标调整方式 | 放大 + 亮黄色（#FBBF24）+ 内联 SVG（与项目图标风格一致） |
| 分类管理入口 | 新建「用户中心」页，Tab 导航「我的」入口 |
| 已删除分类显示 | 原色 + 虚线矩形 + 对角线；可恢复删除 |
| 色盘规格 | 20 色固定色盘 |
| 分类上限 | 10 个（含已删除），超出时提示拒绝 |
| 统计视图 | 独立 Tab；周（堆叠柱状图）+ 月（环形饼图）|
| 统计维度 | 分类时长 + 投入度分布 |
| 周定义 | 自然周（周一~周日）|
| 图表类型 | 周：堆叠柱状图；月：环形饼图 |
| 空状态 | 显示占位空状态图（骨架轮廓），不报错 |
| 日历 ⚡ 点击 | 跳转当天详情页 |
| 已删除分类在新增表单 | 显示但不可选（删除样式） |
